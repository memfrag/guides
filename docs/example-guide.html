Example Guide

A starter template for new guides.

Structure

Each guide is a standalone HTML page under docs/, styled with the shared stylesheet at assets/style.css. Copy this file as a starting point for a new guide.

Adding a new guide

  1. Create docs/your-guide.html, copying this file's structure.
  2. Add an entry to guides.json at the repo root with a title, description, and path.
  3. Commit and push — the index page picks it up automatically.
